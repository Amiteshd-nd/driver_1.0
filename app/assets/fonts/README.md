# Satoshi font files

Self-hosted from Fontshare (Indian Type Foundry; free for personal and commercial use). Declared in `pubspec.yaml` under `fonts:`. The web surfaces load the same family from `design_system/fonts/satoshi.css`. Fraunces and Manrope were retired on 2 Oct 2026 and are recorded in `design_system/tokens.json` → `typography.retired`.
