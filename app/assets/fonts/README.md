# Satoshi font files

Download Satoshi from https://www.fontshare.com/fonts/satoshi (free for commercial use) and place these files here:

- Satoshi-Regular.otf · Satoshi-Italic.otf · Satoshi-Medium.otf · Satoshi-Bold.otf · Satoshi-Black.otf

They are declared in `pubspec.yaml` under `fonts:`. The web surfaces load Satoshi from Fontshare's CDN instead. Fraunces and Manrope were retired on 2 Oct 2026 and are recorded in `design_system/tokens.json` → `typography.retired`.
